# Claims and evidence

Checked on 2026-09-15.

## Verified

- Robinhood Chain is an EVM-compatible Arbitrum Layer 2. Mainnet chain ID is `4663`, ETH is the gas token, and the public RPC is `https://rpc.mainnet.chain.robinhood.com`. Source: [Robinhood Chain documentation](https://docs.robinhood.com/chain/connecting/).
- `flybrain 0.1.0` is published on PyPI. It exposes the MaleCNS v1.0 connectome as a spiking network with 166,700 neurons and 25.6 million neuron-to-neuron connections. Source: [PyPI](https://pypi.org/project/flybrain/) and [source repository](https://github.com/alextitonis/fly.ai).
- The underlying MaleCNS map contains more than 166,000 neurons and about 125 million synaptic connections. Source: [Google Research](https://research.google/blog/a-connectomics-milestone-mapping-the-complete-male-fruit-fly-brain/).
- FOMO Radar publicly displays Robinhood Chain wallet signals and states that its fused view reads the chain every twenty seconds. Source: [FOMO Radar](https://fomoradar.app/).

## Not claimed

- `$500 -> $19,400` is a narrative simulation number supplied for the video concept. It is not verified performance and does not appear as a product result.
- FLYWHEEL does not claim that a connectome predicts prices or outperforms a conventional model.
- FLYWHEEL does not claim that the browser visualization runs 166,700 neurons. The default is an explicitly labelled deterministic surrogate.
- FLYWHEEL does not claim a working FOMO API integration. No public API contract was found, so v0.1 uses fixtures behind an adapter boundary.
- FLYWHEEL does not submit Robinhood Chain transactions.
